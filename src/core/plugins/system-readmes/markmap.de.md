Mindmaps verwandeln eine Markdown-Gliederung in eine interaktive Mindmap direkt in deiner Notiz.

## Verwendung

- Tippe `/` in eine leere Zeile und wähle **Mindmap**, oder tippe ```` ```markmap ```` gefolgt von einem Leerzeichen in eine leere Zeile.
- Klicke auf die Kopfzeile des Blocks, um den Editor zu öffnen, bearbeite die Gliederung und wähle **Anwenden**. Mit **Löschen** entfernst du den Block.
- Schreibe die Map als verschachtelte Markdown-Überschriften (oder Listen); jede Überschrift wird zu einem Zweig:

```markdown
# Thema
## Idee A
## Idee B
```

## Hinweise

- Sehr große Gliederungen (über 100.000 Zeichen) werden nicht gerendert, damit die App reaktionsfähig bleibt.
- Beim Deaktivieren des Plugins verschwinden der Einfügebefehl und die Darstellung des Blocks; die Gliederung bleibt in der Notiz gespeichert.
