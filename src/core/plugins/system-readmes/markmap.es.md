Los mapas mentales convierten un esquema Markdown en un mapa mental interactivo dentro de tu nota.

## Uso

- Escribe `/` en una línea vacía y elige **Mapa mental**, o escribe ```` ```markmap ```` seguido de un espacio en una línea vacía.
- Haz clic en la cabecera del bloque para abrir su editor, edita el esquema y elige **Aplicar**. **Eliminar** quita el bloque.
- Escribe el mapa como títulos Markdown anidados (o listas); cada título se convierte en una rama:

```markdown
# Tema
## Idea A
## Idea B
```

## Notas

- Los esquemas muy grandes (más de 100 000 caracteres) no se renderizan, para mantener la aplicación fluida.
- Desactivar el plugin oculta el comando de inserción y el renderizado del bloque; el esquema sigue guardado en la nota.
