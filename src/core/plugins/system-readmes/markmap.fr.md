Les cartes mentales transforment un plan Markdown en carte mentale interactive intégrée à votre note.

## Utilisation

- Tapez `/` sur une ligne vide et choisissez **Carte mentale**, ou tapez ```` ```markmap ```` suivi d'une espace sur une ligne vide.
- Cliquez sur l'en-tête du bloc pour ouvrir son éditeur, modifiez le plan, puis choisissez **Appliquer**. **Supprimer** retire le bloc.
- Écrivez la carte sous forme de titres Markdown imbriqués (ou de listes) ; chaque titre devient une branche :

```markdown
# Sujet
## Idée A
## Idée B
```

## Remarques

- Les plans très volumineux (plus de 100 000 caractères) ne sont pas rendus, afin de garder l'application réactive.
- Désactiver le plugin masque la commande d'insertion et le rendu du bloc ; le plan reste enregistré dans la note.
