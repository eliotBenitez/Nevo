Синхронизация с GitHub создаёт резервную копию рабочего пространства в репозитории GitHub. Это односторонняя выгрузка: Nevo никогда не загружает и не объединяет изменения обратно в ваше пространство.

## Настройка

- Откройте плагин, нажмите **Настроить** и заполните параметры ниже.
- **Репозиторий**: в формате `owner/name`.
- **Ветка**: ветка для резервной копии (`main`, если поле пустое). Используйте отдельную ветку или репозиторий.
- **Токен доступа**: personal access token с правом `repo`. Он хранится в защищённом хранилище операционной системы, а не в рабочем пространстве.
- **Сообщение коммита**: сообщение для каждого коммита резервной копии (`Nevo backup`, если поле пустое).
- **Автосинхронизация** и **Интервал (минуты)**: выгрузка по таймеру, от 1 минуты до 24 часов. Первая автоматическая синхронизация выполняется после целого интервала.

## Как пользоваться

- Нажмите **Проверить подключение**, чтобы проверить репозиторий и токен.
- Нажмите **Синхронизировать сейчас** для немедленной выгрузки. Статус показывает время последней синхронизации и число файлов.

## Что выгружается

- Заметки, папки, вложения, доски, базы данных, шаблоны и история, как при экспорте рабочего пространства. Установленные плагины не включаются.
- Файлы, которые уже совпадают с репозиторием, повторно не загружаются.
- Файлы крупнее 25 МиБ пропускаются, а всё рабочее пространство не должно превышать 512 МиБ.

## Примечания

- Ветка заменяется копией рабочего пространства: файлы, которых в нём нет, удаляются из ветки, а история коммитов сохраняется.
- Для одного рабочего пространства одновременно может выполняться только одна синхронизация.
