Диаграммы Vega-Lite превращают JSON-спецификацию в интерактивную диаграмму прямо внутри заметки.

## Как пользоваться

- Введите `/` в пустой строке и выберите **Диаграмма**, чтобы вставить блок с диаграммой.
- Щёлкните по блоку, чтобы открыть редактор, вставьте или напишите спецификацию Vega-Lite (JSON) и нажмите **Применить**. Кнопка **Удалить** убирает блок.
- Типичная спецификация задаёт `mark`, данные `data.values` и `encoding`:

```json
{
  "$schema": "https://vega.github.io/schema/vega-lite/v5.json",
  "mark": "bar",
  "data": { "values": [{ "a": "A", "b": 28 }] },
  "encoding": { "x": { "field": "a" }, "y": { "field": "b" } }
}
```

## Примечания

- Диаграмма следует теме приложения и переключается между светлыми и тёмными цветами.
- Если спецификация некорректна, вместо диаграммы блок показывает ошибку; исправьте JSON, и диаграмма появится снова.
- Очень большие спецификации (более 100 000 символов) не отображаются, чтобы приложение оставалось отзывчивым.
- Если отключить плагин, команда вставки и отображение блока скрываются; спецификация остаётся в заметке.
