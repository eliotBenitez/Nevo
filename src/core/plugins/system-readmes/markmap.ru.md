Интеллект-карты превращают Markdown-структуру в интерактивную интеллект-карту прямо внутри заметки.

## Как пользоваться

- Введите `/` в пустой строке и выберите **Интеллект-карта** либо введите ```` ```markmap ```` и пробел в пустой строке.
- Щёлкните по заголовку блока, чтобы открыть редактор, измените структуру и нажмите **Применить**. Кнопка **Удалить** убирает блок.
- Записывайте карту вложенными заголовками Markdown (или списками); каждый заголовок становится ветвью:

```markdown
# Тема
## Идея А
## Идея Б
```

## Примечания

- Очень большие структуры (более 100 000 символов) не отображаются, чтобы приложение оставалось отзывчивым.
- Если отключить плагин, команда вставки и отображение блока скрываются; структура остаётся в заметке.
