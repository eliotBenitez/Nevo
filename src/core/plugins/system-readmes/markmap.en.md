Mind maps turn a Markdown outline into an interactive mind map that lives inside your note.

## Usage

- Type `/` on an empty line and choose **Mind map**, or type ```` ```markmap ```` followed by a space on an empty line.
- Click the block header to open its editor, edit the outline, then choose **Apply**. Use **Delete** to remove the block.
- Write the map as nested Markdown headings (or lists); each heading becomes a branch:

```markdown
# Topic
## Idea A
## Idea B
```

## Notes

- Very large outlines (over 100,000 characters) are not rendered, to keep the app responsive.
- Disabling the plugin hides the mind map command and block rendering; the outline stays saved in the note.
