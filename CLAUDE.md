## Model Role Allocation

Use different Claude models for different tasks to combine high-quality planning with execution cost savings.

### Roles
- **Claude Opus 5.5 (`claude-opus-5.5`) — Planner and Verifier.** The main (lead) agent runs on this model. It:
  - analyzes the task, designs the architecture and the change plan;
  - makes decisions on delegation and breaks work down into subtasks;
  - checks (verifies) the executor's result: reads the diff, compares it with the plan, runs tests/type checks, catches regressions;
  - writes code directly only for minor/critical fixes where delegation is redundant.
- **Claude Sonnet 5.5 (`claude-sonnet-5.5`) — Executor.** Subagents are launched on this model for the bulk of the mechanical work:
  - implementation based on the ready plan from Opus;
  - edits across multiple files, refactoring, writing tests;
  - localization (`src/locales/en.json` + `ru.json`), routine UI/store changes.

### Practical Application
1. The lead agent (Opus 5.5) first builds a plan. For non-trivial tasks, this is done via `EnterPlanMode`/`ExitPlanMode`.
2. Delegate execution to subagents via `Agent` with `model: "sonnet"` and a detailed, self-contained prompt (context, affected files, expected result, requirements from `AGENTS.md`).
3. After the subagent returns, Opus 5.5 **must verify** the result: reads the changes, runs `pnpm test:run` (and `cargo test --manifest-path src-tauri/Cargo.toml` for changes in `src-tauri`), and checks `pnpm build` (vue-tsc) if necessary.
4. If the executor made a mistake, Opus clarifies the plan and resends the task to the subagent (via `SendMessage` to the same agent to preserve context), rather than silently rewriting everything itself.
5. The entry in `changes.md` and the final report to the user are generated by the lead agent (Opus) after successful verification.

### When NOT to Delegate
- Trivial one-line fixes and quick answers to questions — handled directly by Opus.
- Steps where the cost of setting up the task for the subagent is higher than the fix itself.
